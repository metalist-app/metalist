# Menu actions

Use this reference to explain MetaList accurately. It describes user capabilities,
not permission or tools for you to execute every operation. You can answer and
request one supported menu/dialog opening. You cannot submit a form, change
settings, run a shell command, or mutate notes through this help response. Do not
claim that you inspected current notes or settings: none are supplied here.
Prefer user-facing steps over implementation details. If the reference does not
answer a question, say what is unknown; do not invent syntax or controls.

Sources: docs/ui/command-palette.md

What each of the command palette's utility actions does. The palette itself, its preference controls (`Theme` and the rest) and views are in the menus topic.

## Utility Actions
- `Back Up Now…`: opens Backup Settings, where the user chooses one backup folder, picks which vaults to include (remembered from the last backup; new vaults start checked; the vault in use is always included and can't be unchecked), and sets the retention count. Suggested folders: Downloads, then a MetaList Backups folder in each synced folder found (Dropbox, Google Drive, OneDrive, iCloud Drive); a synced folder keeps backups off the computer. A vault without a password asks once before going into a synced folder. `Back Up Now` submits those settings directly to the backend operation that persists them and creates the archives; the completion modal appears only after concrete archive results return and shows the created size per vault. Typing `backups` in the palette also matches this action.
  - Each backup snapshot is one versioned `.tar.gz` archive containing the notes DB plus sibling files DB when present.
  - The completion modal shows one result row per vault.
- `Backup Reminder`: `Off`, `Daily`, `Weekly` (the default), `Every 2 weeks` or `Monthly`, saved per vault; Enter cycles it like `Theme`. When this vault's newest backup in the backup folder is older than that (or there is none), a card floats at the bottom right: `Time to back up: the last backup was 9 days ago.` with `Back Up Now` (opens Backup Settings, as `Back Up Now…` does) and `×` (hides it for a day). It is not a Reminders reminder. It takes no space and never takes focus; it waits while a dialog or the menu is open, stays until a backup succeeds (cancelling Backup Settings keeps it), and goes away when set to `Off`. It is checked when MetaList opens, when its tab comes back, when a dialog or the menu closes, and on the first click or key after a while.
- `Restore from Backup…`: opens a restore picker for configured-folder snapshots, applies the selected archive, then shows a success confirmation with `OK` before reload.
  - Restore reuses the same archive pipeline for both sources and recreates the sibling files DB from the archive contents. The source archive and legacy sidecars remain byte-for-byte unchanged; legacy search-history sidecars are ignored.
- `Export View as HTML…`: downloads a self-contained HTML file of the current view as shown (its search, sort order, Untagged view; notes the search leaves out are absent, not grey bars) with inline CSS, the active light/dark theme, notes starting collapsed and expanded as MetaList shows them (embeds too; the note being edited open), no command/search chrome, MetaList's collapse arrows (one collapses its note to the first line and hides its children), and click-to-copy for usernames, included passwords and `@copyable` values. A dialog comes first: the title (default selected: the note's first line, `MetaList`, `MetaList — <search>` or `MetaList — Untagged notes`; it heads the file and names it, `Spring in Kyoto.html`), `🤖 Suggest with AI` with an AI set up (only pressing it asks; it never sees private notes, passwords or the search), and, if it shows `@password` or `@username` notes, an `Include Unredacted Passwords` / `Usernames` / `Usernames and Passwords` checkbox (unchecked: each shows `••••••••`; checked: plain and readable). The title heads the file unless the first note already says it.
- `Import…`: a full-window wizard bringing in an Obsidian vault, a Markdown folder or Any folder (a folder of any files). Steps: Source; Folder (the system's folder dialog, and the folder it will appear under in MetaList, the folder's name by default); Files (Any folder only: a checklist of what to import by kind of file, each kind opening to its files with a box each); Markdown (only when Markdown files come in: Any folder first asks Turn into notes or Keep as files; then Split each file and Write as, beside a sample); Images (only when JPEG, PNG, WebP, TIFF or BMP images come in: Keep originals, chosen at first, or Compress: upright, without location and camera data, with the longest side picked from 1280, 1920, 2560 (chosen at first) or 3840 pixels, each showing about what the images come to at that size; GIF, SVG, HEIC, AVIF and animated images always come in unchanged, and an image compression wouldn't make smaller comes in as it is); Previews (Any folder only, when ticked files have one: which kinds get a preview, a note under each file holding its text so search finds it, stored as note data beside the file; Code, Web pages, CSV and JSON, none ticked at first, each showing how many files and about how much note data; PDFs get no preview note); Summary; then the import. Anything imported, a single note or a whole folder, goes after the last note in the list, so the notes already there stay where they were. A floating message says what came in ("Imported 340 notes into `My-Vault/`."). Once done it closes on a new search context of the imported notes (loose files dropped on the page instead stay in the search context they were dropped in, the list scrolling to the first of them). Imported notes never take the tags of the search showing. A file's name comes in as a heading over its text, or, when split, as a heading note over its parts. **Browser bookmarks** (a file a browser exports: Chrome, Edge, Brave, Safari, Firefox) goes Source; File (Choose File…, the file's name with how many bookmarks in how many folders, and the folder it goes under, `Bookmarks` at first); Summary (what comes in, and what is left out: only website addresses come in, so files on the computer, browser pages, bookmarklets and Firefox's smart folders are listed there by title); then the import. Each bookmark becomes one note, its title linked to its page, tagged with its folders under `Bookmarks/`, created on the day it was bookmarked; the browser's toolbar isn't a folder of its own. Nothing is fetched from the bookmarked sites. Dropping a bookmarks file on MetaList asks first: Import Bookmarks (the default) or Keep as File. Importing the same file again brings it all in again, under its own import tag: an import only adds. While it imports, its bar fills by files stored, with the time so far and about how long is left; a folder dropped on the page has a Copy step first, its own bar filling as the ticked files are copied.
- `Print View…`: prints the current view as shown through the browser's print dialog (Save as PDF included): always light, fully expanded, MetaList's colours kept (embed tints), no arrows. The same dialog comes first (title, `🤖 Suggest with AI`, Include passwords); Enter prints, Escape cancels. It uses the page's full width with its own margins, so the browser prints no header or footer. The title heads the first page and names the PDF.
- `Log Out`: revokes the current session and returns to login.
- `Generate Random Password…`: opens a password generator modal, `Made of` Characters (length, character set) or Words (5 random words by default, up to 7), with explicit `Copy` and `Regenerate` actions, the standard modal `×`, and a clipboard handoff that auto-adds `@password` when that copied value is pasted into an empty note.
- Password alphabets ignore line breaks and duplicate characters; each distinct Unicode code point has equal selection probability. Length counts Unicode code points, so an ordinary emoji counts as one; combined emoji sequences may contain several code points.
- `Session Idle Timeout…`: opens a modal for changing the vault-scoped inactivity window before reauthentication is required again, or disabling idle timeout entirely.
- `Open Reminders`: opens the privacy-first in-app reminder registry and builder. Reminders are vault-local, encrypted with the vault when password protection is enabled, and never use browser/system push notifications. See `docs/ui/reminders.md`.
- `Keyboard Shortcuts`: opens the keyboard shortcuts cheatsheet from the command palette; `cheatsheet` is a searchable keyword.
- `Version Info`: opens a read-only runtime/version modal with app version, SQLite `user_version`, vault, auth, encryption, encryption format version, KDF, and cache readiness fields.
- `Memory Usage`: opens a read-only modal with this vault's server process memory now and at its peak (on macOS the footprint Activity Monitor shows, elsewhere resident memory; a Measured as row says which), how many notes it holds decrypted in memory and the size of their text, and how long the server has run; Refresh reads them again. Measure what holds it measures, in a few seconds, how much each part of the server holds (the note text cache, the note store, the search index, the `[[` suggestions, rendered views, open views, link titles, attachments, undo history) and what is left for Python and its libraries; sizes only, never content, and saving waits while it measures. Copy puts everything the dialog shows on the clipboard as plain text (the breakdown too, once measured). It is the server process (which holds the decrypted notes), not the browser's memory.
- `Recent Messages`: lists the last 20 floating messages (news, errors, the connection card), newest first, with the time each showed, so one that left before it was read is not lost. Kept in the page's memory only; signing out forgets them.
- `Note Layout & Appearance…`: previews and saves the note hierarchy presets. Search terms include `layout`, `appearance`, `font`, `size`, `spacing`, `indentation`, and `hierarchy`.
- `Search Suggestion Stats & Settings…`: combines ordered personalized-window editing, promoted-suggestion label visibility, default-on per-context note-credit suppression, retained daily tag-credit statistics, and confirmed activity reset. It does not collect search text or note content.
- `AI Agent Settings`: four folder tabs and one Save. **Keys**: a switch per provider (OpenAI, Anthropic, Google), each with its API key and usage and billing link. **Privacy**: the cloud privacy rules (blacklist and whitelist). **Reading**: web access, and Model window used (a percentage of each model's context window, one limit for answers and tagging). **Tagging**: which tags the AI may propose, existing tags only or existing and new tags. `Cloud AI Privacy…` opens it on Privacy and `AI Tagging Vocabulary…` on Tagging. Model and thinking level are picked only beside chat Send; picking a model picks its provider. See `docs/ui/ai-chat.md`.
- `Open/Switch Vault…`: opens a simple vault picker with two buttons. `Open in This Tab` loads the selected non-current vault in the same tab, on its login screen, so switching back and forth keeps one tab (Back returns to the previous vault). `Open in New Tab` opens it in a new browser tab and leaves the current tab as it is. With no other vault yet, it opens Create Vault… instead.
  Either way, a running vault with an unchanged launch profile keeps its process and warm cache; stopped vaults launch, and changed port profiles restart the target. Each vault still permits only one active browser tab/session.
- `Create Vault…`: a full-window wizard. Its first step asks the vault's name and ports (defaulted to free ones); Create Vault launches the vault and opens it in a new tab, straight into the rest: a password (Generate Password… can make one), an AI and its key, and bringing in notes from Obsidian or a Markdown folder (or starting empty), then a summary and Set Up Vault. Setting the password there keeps you logged in. Launch-time port races fail without terminating the process that owns the port. Running vault servers revalidate their on-disk vault identity every five seconds and terminate themselves if their database or launch profile disappears.
- `Manage Vault Ports…`: opens a table of saved launch profiles from each vault's main DB; saving this table only updates future launch profiles and does not switch browser tabs, launch vaults, or restart the current process. Current-vault port edits apply on the next MetaList launch.
- `Delete Vault…`: asks which vault to delete, then opens a destructive confirmation view for that target. The confirm button is red and the user must type the vault name. Deletion never requires the vault password, so an inaccessible encrypted vault can still be removed. Deleting the active vault moves the tab to a dedicated vault-removal status page; deleting an inactive vault stays in the current search context and reports completion in the modal.
- `Attach File…`: opens the native file picker, uploads the selected file, and inserts an embedded file reference token into the current note. If no note is active, it creates a new note first.
- `Link to…` / `Embed…`: type `[[` or `![[` at the caret of the note being edited (or in a new note at the top when none is) and open the note suggestions, the note copied last first.
- `Insert LaTeX` / `Insert CSV` / `Insert Mermaid Diagram` (also `Insert ▸` in the note's right-click menu while editing): type the region's delimiters at the caret with the caret inside, so its preview shows as you type: in a Markdown note `$$…$$` or a mermaid fence; otherwise a wrapper the note doesn't use yet, its tag added to the tag bar (as Add Style). Selected text goes inside. Not offered where the whole note is already that format.
- `Insert Password` (also `Insert ▸ Password` while editing): a new random password. An empty note becomes it, tagged `@password`; otherwise it goes in a `{…}` region, `{@password}` added, so only it shows as dots.
- `Add Excalidraw Diagram`: attaches a new, empty Excalidraw diagram to the current note (or a new note when none is active) and opens the full-screen diagram editor.
- `Trim Unused Files…`: deletes files no note's content references, after a confirmation naming how many and how big. It keeps files that ⌘Z or pasting a copied note could bring back. It is the only cleanup for unused files, and a manual one.
- `Trim Reminder`: `On` (default) or `Off`, per vault. Once unused files add up to 10 MB, a card offers `Trim Unused Files…`; `×` hides it until another 10 MB piles up. Deleting a folder's notes or a view's notes checks at once.
- `Retry Failed Link Titles…`: asks every web link whose title lookup failed (rate limited, refused, login or verification page, no title, timed out, page not found and other errors) again now. It opens a dialog saying how many links it would ask; nothing runs until its **Retry N links** button (or Enter). Unsupported links (such as PDFs) and private-network links are not retried. It uses the usual polite pacing: one request per site at a time, 2 seconds apart; a site that answers "too many requests" is skipped for the rest of the run and its links keep their normal retry schedule. The same dialog then shows progress: links asked, titles found, what still fails and why, and skipped sites. It does not block the app: closing the dialog (×, Escape or a click outside) leaves the retry running, and running the action again shows its progress instead of starting another. **Stop** drops the lookups not yet started; logging out, locking or logging in also stops it. Titles found appear in notes at the next view refresh.
- `Prioritize Tag to Front (Global)…`: opens a warning modal with single-tag input and suggestions from all root notes. Applying it stably moves all matching root notes to the front of the global root order while preserving relative order inside the matching and non-matching groups. Cmd+Z cannot undo this action; the undo/redo queue is cleared.
- `Prioritize Tag to Back (Global)…`: same as above, but stably moves all matching root notes to the back of the global root order.
- `Alphabetize Root Notes A-Z (Current View)…`: after confirmation, permanently rearranges only root-level notes in the active search context by root-note content. Hidden roots and child notes are not reordered. Cmd+Z cannot undo this action; the undo/redo queue is cleared like a view-context switch.
- `Alphabetize Root Notes Z-A (Current View)…`: same as A-Z, but descending by root-note content.
- `Repair: Reset Updated Time to Created Time (Current View)…`: after confirmation, resets every note inside each matching root subtree in the active search context so `updated_at = created_at`. Notes outside the current view are not changed. Cmd+Z cannot undo this action; the undo/redo queue is cleared.
